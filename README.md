# For Pratiksha

> A quiet cinematic website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

---

## Personalization

**Edit one file: [`data/story.ts`](./data/story.ts)**

Everything — name, text, captions, observations, memories, music path — lives there. No other file needs to be touched for content changes.

## Media Checklist

| Folder | Files needed |
|---|---|
| `/public/images/` | `photo-01.webp` through `photo-06.webp` |
| `/public/videos/` | `memory-01.mp4` through `memory-04.mp4` (silent) |
| `/public/audio/`  | `dandelions.mp3` |

## Deploy

1. Push to GitHub
2. Connect repo to [Vercel](https://vercel.com)
3. Deploy — no build configuration needed

## Tech Stack

- Next.js 14 (App Router, static export)
- TypeScript
- Tailwind CSS
- Framer Motion
- Google Fonts (Playfair Display, Cormorant, DM Mono)
